# Fretline 호환성 경계

이 문서는 지원 범위, 보장하지 않는 것, 앱 기본값으로 정한 동작을 적는다.
같은 내용이 앱의 **도움말 > 호환성**(`help.compatibility`)에 내장되어 있다. 열린 파일의 실제 상태는
악보 위 호환성 배지와 보고서가 항목별로 보여 준다. 호환 정도를 비율이나 전체 보장으로 적지 않는다.
읽기 항목의 근거는 `tests/fixtures/gp/*.expected.json`과 형식별 가져오기 QA 실행 결과다.

상태 표기: **지원** / **미지원** / **검증 안 됨**(보존 여부를 확인하지 못함) / **앱 기본값**(Fretline이 정한 동작).

## 파일 형식

| 항목 | 상태 | 설명 |
| --- | --- | --- |
| GP3 · GP4 · GP5 · GPX(GP6) · GP7 · GP8 읽기 | 지원 | 열기 후 보고서가 항목별 상태를 보여 준다. 보고서에 없는 항목이 손실 없이 읽혔다는 뜻은 아니다 |
| `.gp` 쓰기 (형식 8.1.3) | 지원 | 별도 내보내기. 음표·리듬·트랙·튜닝·반복·선언된 주법. 손실 항목은 내보내기 전에 표시. 형식 7까지만 읽는 프로그램에서는 열리지 않을 수 있다 |
| GP3 · GP4 · GP5 · GPX 쓰기 | 미지원 | 메뉴에 없다. `.gp` 내보내기만 제공한다 |
| GP 파일 바이트 단위 왕복 | 미지원 | 열었다가 다시 내보낸 `.gp`가 원본과 같은 바이트라고 약속하지 않는다. 원본은 `원본 파일 내보내기`로 그대로 꺼낸다 |
| MusicXML 4.0 (`.musicxml` / `.mxl`) | 지원 | 성부·화음·쉼표·붙임줄·잇단음표·반복·가사·줄/프렛. GP 전용 표기·오디오 설정은 보고서에 표시 |
| MIDI (SMF 0/1 읽기, SMF 1 쓰기) | 지원 | 읽을 때 1/16(또는 셋잇단) 그리드 양자화 미리보기 확인 후 문서가 된다. 주법·표기는 MIDI에 없어 복원되지 않는다 |
| PowerTab · TablEdit · ASCII 탭 | 미지원 | 열거나 저장할 수 없다 |

## 음색과 재생

| 항목 | 상태 | 설명 |
| --- | --- | --- |
| 전용 음색 · 페달 모델 | 미지원 | 내장 SoundFont 신디사이저(alphaTab)로 소리를 낸다. 파일을 만든 프로그램의 전용 음색·이펙트 체인·페달 설정과 같은 소리가 나지 않으며 파일 안의 그 설정은 읽지 않는다 |
| 오버드라이브 · 디스토션 기타 (GM 29 · 30) | 앱 기본값 | 샘플 대신 클린 일렉 기타를 내장 앰프 단에 통과시켜 소리를 낸다. 트랙 중간의 음색 변경으로 드라이브가 켜지거나 꺼지는 것은 따라가지 않고, 트랙의 첫 음색으로 정한다 |
| GP 파일 안의 읽지 않은 정보 | 검증 안 됨 | 보고서의 "검증 안 됨" 항목은 보존 여부를 확인하지 못한 정보다. 편집 사본으로 바꾸면 내보낸 파일에 들어가지 않는다 |
| 트랙 볼륨 · 팬 · 음소거 · 솔로 · EQ | 지원 | Global View 믹서와 트랙/마스터 EQ. 반주와 악보 소리는 같은 오디오 시계로 재생 |
| GP 볼륨·팬 자동화 | 부분 지원 | GP3~5 mix-table 값을 MIDI 0~127로 반올림·포화한 뒤 볼륨 0~1, 팬 -1~1로 읽는다(엔진 8은 CC64). alphaTab 1.9.0은 GPX/GP7/GP8의 중간 볼륨·팬 변경을 읽지 않으며 `.gp` 출력도 이를 생략하고 보고한다 |
| GP 진행 기호 | 부분 지원 | GP5/GPX/GP7/GP8의 D.C./D.S., Segno/Coda/Fine, al Coda/al Fine을 읽는다. GP3/4는 엔진이 기호를 제공하지 않는다. 겹 기호·대상 누락·한 마디의 복수 진행 명령은 원본에만 보존하고 보고한다 |
| 파일 안의 불완전한 데이터 | 정리해서 읽음 | 덜 채워진 잇단음표는 쉼표로 채우고, 이웃하지 않은 음을 잇는 붙임줄은 풀고, 타격 없는 드럼 붙임줄과 읽을 수 없는 음표는 빼고, 범위를 벗어난 템포·카포와 짝이 맞지 않는 반복 기호는 바로잡는다. 정리한 내용은 가져오기 보고서에 항목별로 한 줄씩 건수와 함께 표시된다 |
| MIDI 반복·점프의 템포 | 지원 | 각 방문 마디 시작에 원래 악보 위치의 상속 템포를 다시 쓰므로 반복·점프 전 마디의 템포가 잘못 이어지지 않는다 |
| 반주 동기화 중 고정 템포 | 미지원 | 동기화가 켜져 있으면 고정 템포가 비활성이다 |
| 혼합 재생 지연 · 커서 오차 | 측정 실행 통과 | `mixed-clock` QA 케이스의 48 kHz 스테레오, 50/100/150% 속도 실행에서 경로 간 오차·누적 드리프트 ≤20 ms, 진행하는 커서 전환의 소리 대비 오차 ≤50 ms 검사를 PASS했다. 다만 커서 오차 50 ms 초과가 6회 실행 가운데 2회(141.8 ms, 90 ms) 있었고 원인은 특정하지 못했다(`runs/w6/fx-ui-render.md`; 해당 구간은 실행 시간에 비해 CPU 사용이 매우 적었다). 해당 실행의 결과이며 모든 하드웨어·부하에서의 보장 수치는 아니다 |

## 설명서에 없어 앱 기본값으로 정한 동작

| 상황 | 앱 기본값 |
| --- | --- |
| `Esc` 후 반복 | 선택을 지운다. 반복이 켜진 채라면 다음 재생은 곡 전체를 반복한다 |
| 반복 끄기 | 현재 재생은 곡 끝까지 이어지고 선택은 유지된다 |
| 선택 구간 안의 반복 기호 | 선택 구간 연습은 안쪽 반복·엔딩·진행 기호를 무시하고 한 번 선형으로 연주한다. 곡 전체 재생은 기호를 따른다. "악보 반복 따르기" 옵션으로 바꿀 수 있다 |
| 반복 중 구간 밖 클릭 | 편집 커서만 옮겨지고 재생은 구간 안에 머문다. 새로 드래그하거나 선택을 지워야 구간이 바뀐다 |
| 반복 중 탐색 | 구간 밖 이동 요청은 경계로 고정된다. 정지는 구간 시작으로 돌아간다 |
| Windows 명령 팔레트 키 | 부록은 macOS ⌘E만 적는다. Windows 키맵은 Ctrl+E |
| 음 길이 바꾸기와 채우기 | 늘리면 바로 뒤 쉼표만 흡수, 마디를 넘치면 다음 마디로 붙임줄 분할, 다른 음과 겹치면 명령 거부 |
| 애매한 부록 키 | 플랫폼별로 뜻이 갈리는 키는 메뉴로만 실행한다. 관찰된 GP 동작으로 주장하지 않는다 |

## 제공하지 않는 기능

| 항목 | 상태 | 설명 |
| --- | --- | --- |
| mySongBook · 클라우드 계정 · 협업 | 미지원 | 온라인 서비스가 없다. 모든 기능은 로컬 파일로 동작 |
| VST / AU · 외부 MIDI 하드웨어 · Line-in 앰프 모델링 · Fretlight | 미지원 | 메뉴에도 없다. 튜너 마이크 입력과 앱 내 EQ는 제공 |
| 원본 프로그램과 같은 픽셀 단위 악보 배치 | 미지원 | 기보 엔진이 다르다. 줄 바꿈·박 간격은 디자인 모드에서 직접 조정 |
| Windows · Linux 실행 | 검증 안 됨 | macOS(Apple Silicon) 빌드만 검증했다 |
| 서명된 배포 · 앱스토어 | 미지원 | 로컬 unsigned `.app`/`.dmg`만 만든다 |

## 파싱 한계

압축 파일 256 MiB, 압축 해제 프로젝트 1 GiB, 항목 4096개, 개별 오디오 512 MiB, XML 64 MiB, 보관함 중첩 1단계.
한계를 넘으면 잘라내지 않고 오류를 표시한다. 경로 탈출·중복 이름·심볼릭 링크·XML DTD/외부 엔티티는 거부한다.

## 근거

- alphaTab 1.9.0 형식 문서(GP3–5, GP6, GP7, GP8 필드 지원표)와 내보내기 범위.
- 자체 QA 증거: `qa-evidence/` 아래 작업별 `result.json`. 증거가 없는 항목은 "지원"으로 적지 않았다.
