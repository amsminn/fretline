# Fretline 사용 설명서

Fretline은 GP 형식 악보를 열고 편집·연습·출력하는 오프라인 macOS 앱이다. 같은 내용이 앱 안의
**도움말 > 사용 설명서**(`help.guide`)에 들어 있으며, 거기서는 명령 링크를 눌러 바로 실행할 수 있다.
단축키 전체 표는 [shortcuts.md](shortcuts.md), 지원·미지원 경계는 [compatibility.md](compatibility.md)에 있다.

## 악보 열기와 문서 탭

- `파일 > 열기`(⌘O)로 GP3·GP4·GP5·GPX·GP7·GP8, MusicXML(.musicxml/.mxl), MIDI(.mid), `.fretline` 파일을 연다.
- 문서마다 탭이 생기고, 저장되지 않은 변경은 탭의 점으로 표시된다. `⌘W` 닫기, `⌘⇧W` 모두 닫기.
- GP 파일을 열면 **호환성 보고서**가 먼저 뜬다. 읽은 항목은 "지원", 읽지 않은 항목은 "검증 안 됨"이다.
  원본 바이트는 프로젝트 안에 그대로 보관된다. 편집하려면 `편집 가능한 사본으로 변환`을 누른다.

## 저장과 GP 내보내기는 다르다

| 하고 싶은 것 | 명령 | 결과 |
| --- | --- | --- |
| 작업 저장 | `파일 > 저장`(⌘S) | `.fretline` 파일. 원본 GP를 덮어쓰지 않는다 |
| `.gp` 파일 | `파일 > GP 파일(.gp) 내보내기` | 별도 `.gp`(형식 8.1.3; 형식 7까지만 읽는 프로그램에서는 열리지 않을 수 있다). 내보내기 전 손실 보고서를 확인해야 쓰인다 |
| 원본 그대로 꺼내기 | `파일 > 원본 파일(바이트 그대로) 내보내기` | 열 때 보관한 바이트를 그대로 복사한다 |

편집 내용은 1초 안에 복구 저장소에 기록된다. 비정상 종료 후 `파일 > 복구`에서 복원·버림·사본 저장을 고른다.

## 편집

- 박을 클릭하고 줄 위에서 숫자를 누르면 프렛이 입력된다. 두 자리 프렛은 숫자를 이어서 누른다.
- 화살표로 이동, Tab / ⇧Tab으로 보표 이동, ⌘↑/⌘↓로 트랙 이동.
- `+`/`=` 음 길이 줄이기, `-`/`_` 늘리기, `R` 쉼표, `.` 부점, `L` 붙임줄, `/` 잇단음표, `G` 꾸밈음.
- 주법: `B` 벤드, `H` 해머온/풀오프, `S` 슬라이드, `P` 팜 뮤트, `V` 비브라토, `X` 데드 노트, `Y` 하모닉스.
- 성부 ⌘1~⌘4, 다성부 편집 ⌘M. 효과는 선택한 음표 전체에 적용된다.
- ⌘Z / ⌘⇧Z 실행 취소·다시 실행, ⌘C/⌘X/⌘V, ⌘⇧V 특수 붙여넣기(튜닝이 달라도 음높이 유지).
- 입력 필드나 대화상자 안에서는 악보 단축키가 동작하지 않는다.

## 드래그한 구간만 반복 연습

1. 악보 위에서 박을 드래그하면 파란 선택 영역이 생긴다. 가장자리를 끌어 조정하고, 거꾸로 드래그해도 같은 구간이다.
2. `F9`(사운드 > 구간 반복)를 켜고 `Space`를 누르면 선택한 첫 음부터 마지막 음 끝까지만 반복된다.
3. 선택이 없으면 커서부터 끝까지 재생한 뒤 곡 전체를 반복한다.
4. 재생 중 선택을 바꾸면 즉시 새 구간으로 옮겨 간다. `Esc`로 선택을 지우면 다음 재생은 곡 전체다.
5. `정지`는 구간 시작으로 돌아가고 `⇧Space`는 처음부터 재생한다.

## 속도·메트로놈·반주

- 재생 속도 10–300%(음높이 유지). 재생 중 `+`/`-`는 5%씩 조절한다.
- 고정 템포(10–400 BPM), 속도 훈련(반복마다 단계 상승), 메트로놈, 카운트인은 사운드 메뉴와 툴바에 있다.
- `사운드 > 반주 가져오기`로 오디오 파일을 불러오면 파형이 악보 아래에 표시된다. 동기점을 찍어 악보와 맞춘다.
  반주 동기화 중에는 고정 템포를 쓸 수 없다.
- 트랙 볼륨·팬·음소거·솔로는 Global View 믹서에서, EQ는 `사운드 > 트랙 EQ / 마스터 EQ`에서 바꾼다.
- 트랙의 기타 음색은 트랙 검사기의 `악기 · 드럼`에서 고른다(나일론, 스틸, 클린, 뮤트, 오버드라이브, 디스토션 등). 오버드라이브와 디스토션은 클린 일렉 기타 소리를 앰프 단(소프트 클리핑과 스피커 필터)에 통과시켜 만들며, 재생과 WAV 내보내기에 똑같이 적용된다. 파일의 트랙이 이 두 음색으로 지정돼 있으면 자동으로 적용된다.

## 화면 구성과 명령 팔레트

| 영역 | 키 |
| --- | --- |
| 편집 팔레트(왼쪽) | F2 |
| 멀티트랙 보기 | F3 |
| Song / Track 검사기(오른쪽) | F5 / F6 |
| 스타일시트 | F7 |
| Global View(아래) | F8 |
| 명령 팔레트 | ⌘E (Windows 키맵: Ctrl+E) |

템포·조표·박자·튜닝·카포·섹션 기호를 악보에서 직접 클릭하면 해당 대화상자가 열린다.

## 인쇄와 출력

- 인쇄(⌘P), PDF, PNG, SVG는 실제 배치된 페이지를 출력한다.
- WAV와 트랙별 WAV는 48 kHz 16비트 스테레오 PCM이다.
- MusicXML, MIDI(SMF 1), alphaTex는 각 형식이 표현할 수 있는 범위로 내보내며, 빠지는 항목은 내보내기 전 보고서에 적힌다.
